# Model OSI dan TCP/IP

## 7 layer OSI (dari atas ke bawah)
7 Application, 6 Presentation, 5 Session, 4 Transport, 3 Network, 2 Data Link, 1 Physical.

## Model TCP/IP (4 layer)
Application, Transport, Internet, Network Access.

## Contoh protokol
- Application: HTTP, HTTPS, DNS, SMTP, FTP.
- Transport: TCP dan UDP.
- Network/Internet: IP, ICMP.

## TCP vs UDP
TCP bersifat connection-oriented, andal (ada acknowledgment dan pengiriman ulang), dan menjaga urutan data. Dipakai untuk web dan email.
UDP bersifat connectionless, tanpa jaminan pengiriman, tetapi lebih cepat dan ringan. Dipakai untuk streaming, game online, dan DNS.

## Perangkat per layer
Switch bekerja di layer 2 (Data Link), router bekerja di layer 3 (Network), hub bekerja di layer 1 (Physical).
